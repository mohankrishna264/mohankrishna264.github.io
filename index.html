What Can I Do For You?

Agentic AI & Multi-Agent Systems

Multi-agent workflows that plan, call tools, and act. Built with LangGraph, MCP servers, and tool calling, with a human approving every action that matters.

RAG & Retrieval Pipelines

Retrieval that returns the right passage. This covers document ingestion and chunking, hybrid keyword and vector search with reranking, permission-aware filtering, and answers that cite their sources, using pgvector, Pinecone, or FAISS.

GenAI Platforms & Governance

Governed inference gateways on Amazon Bedrock. Every model call is inspected and audit-logged, each application gets access only to approved models, and the platform runs across multiple regions so security and risk teams can trace all model traffic.

Backend & Microservices

Java, Spring Boot, and FastAPI services with REST and gRPC APIs, Kafka event streams, Redis caching, and Spring Security role-based access control. Built to hold up at peak throughput and in HIPAA-regulated systems.

Full Stack Development

React and TypeScript front ends over typed APIs, tuned with caching and query optimization to cut page load time and latency.

ML Ranking & Experimentation

ML pipelines for ranking and recommendation models, tracked in MLflow and served online via FastAPI. I also design A/B tests with clear success metrics and significance checks.

Cloud & Hybrid Architecture

AWS (Bedrock, Lambda, S3, EC2, ECS, RDS, CloudWatch, Budgets), Azure OpenAI, and on-premises networking with Microsoft Entra ID, plus Docker, Kubernetes, CI/CD, and Datadog monitoring.

LLM Evaluation & Guardrails

Regression test sets, traced agent runs in LangSmith and Langfuse, and Bedrock Guardrails configuration, so a release only ships when quality is measured and holding.
